# Iteration

The user sees the design early and rough, reacts to it, and each short round brings it closer to the success criteria.

*Falls short:* one big reveal. *Overshoots:* rounds that never end.

## Desirable

- **Early artifact:** a rough draft, sketch or example is shown before the design is worked out.
- **Small loops:** each round changes little, so feedback ties to a specific change.
- **Specific feedback requests:** each draft comes with the questions it is meant to answer.
- **Feedback handled:** each piece of feedback is applied, or answered with a reason.
- **Visible changes:** what changed between versions is stated.
- **Riskiest first:** the least certain parts are tried first, in the cheapest form.
- **Fidelity matched to stage:** early drafts are rough on purpose; polish follows a confirmed direction.
- **Preserved versions:** earlier versions stay available.
- **Willingness to discard:** a rejected draft is dropped, not defended.
- **Exit condition:** a stated point, tied to the success criteria, ends the rounds.

## Undesirable

- **Big reveal:** the design is developed in full before the user sees any of it.
- **Premature polish:** effort goes into finish before the direction is confirmed.
- **Ignored feedback:** comments are acknowledged but change nothing.
- **Silent revision:** a new version arrives with no account of what changed.
- **Wholesale rewrite:** each round changes everything, so versions can't be compared.
- **Regression:** a revision undoes something already agreed.
- **Churn:** versions change without getting closer to the success criteria.
- **Draft attachment:** a rejected approach keeps returning in new forms.
- **Vague ask:** a draft is sent with only "what do you think?".
- **Overwriting:** earlier versions are lost and can't be restored.
- **Endless loop:** iteration has no stated stopping condition.
